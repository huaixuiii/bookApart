# 口岸找房

一个轻量型微信小程序，用来收集、浏览和对比个人找房信息。

## 功能

- 上传每套房源的多张图片和视频。
- 记录价格、位置、小区、户型、面积、通勤、联系人等信息。
- 分别记录优点、缺点、备注、评分和看房日期。
- 首页以卡片形式展示房源，支持左右滑动切换浏览。
- 支持“待看 / 已看 / 喜欢 / 淘汰”状态筛选。

## 使用方式

1. 用微信开发者工具导入当前目录。
2. 在 `project.config.json` 中替换真实小程序 `appid`。
3. 开通微信云开发，并创建数据库集合 `houseListings`。
4. 首次运行后，可直接在小程序里新增房源并上传媒体。

## 云开发说明

- 房源数据存储在云数据库集合 `houseListings`。
- 图片和视频上传到云存储目录 `house-media/`。
- 如果当前环境没有启用 `wx.cloud`，小程序会退回到本地缓存和示例数据，方便先预览界面。

## 第一版限制

- 面向个人使用，不包含多人协作、公开分享和权限管理。
- 媒体限制为每套房源最多 12 张图片、3 个视频。
- 首页只提供状态筛选，不做复杂搜索和排序。
